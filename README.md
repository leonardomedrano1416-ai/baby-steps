# Baby Steps — PWA starter

This is the first real website/PWA starter for Baby Steps.

Included:
- Mobile-first design for iPhone
- Installable PWA manifest
- Service worker/offline shell
- Prenatal check-off button
- Dad's message area
- Sonogram-style background image

Next development steps:
1. Put the site on HTTPS hosting.
2. Add persistent storage/database.
3. Add Dad/Microbia accounts and private access.
4. Add a daily reminder time.
5. Add real iPhone Web Push notifications.
6. Add due-date/pregnancy-week tracking once the due date is known.

Important: the current "Save Dad's message" is a prototype and is not yet shared between two phones. The real shared messaging feature needs a backend/database.
